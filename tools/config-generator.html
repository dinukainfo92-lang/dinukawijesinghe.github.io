About the Network Config Generator

This free network config generator is built for service provider and enterprise network engineers who need to provision or migrate large numbers of devices quickly. Instead of writing repetitive Cisco IOS XR, Juniper JunOS, or Nokia SR OS configurations by hand, you define a single CLI template once — then let the tool substitute your device-specific data automatically.

How it works

  1. Write the template. Paste one working config into the Template box and swap the parts that change per device for {{VARIABLE}} placeholders — for example {{INTERFACE}}, {{IP}}, {{VRF}}. Save Template keeps it for your next visit.
  2. Load your data. Upload (or drag in) a CSV / Excel file whose column names match those variables — one row per device. Download the sample Excel to see the format. No file? Paste Data takes cells copied straight from Excel, and + Add Data lets you type a row in by hand.
  3. Check the data. The Validation panel lists matched, missing and unused variables. Under the table, Duplicate check flags identical rows and repeated values such as a reused IP, VLAN, hostname or interface — click the DUP row number to edit, duplicate or delete that row. The search box filters rows, or jumps straight to a row number.
  4. Validate. Confirms every {{VARIABLE}} has a matching column before you generate anything.
  5. Generate. Generate All builds a config for every row — 10,000+ in milliseconds — or tick devices under Select configs and use Generate Selected.
  6. Export. Copy the output, or download it as a single .txt, an Excel sheet with a Generated Config column, or a .zip holding one file per device (named by your Label by column choice).

Supported platforms

  • Cisco IOS XR (NCS-5500, NCS-540, ASR9k)
  • Cisco IOS / IOS-XE
  • Juniper JunOS (MX, QFX, EX)
  • Cisco NX-OS (Nexus)
  • Arista EOS
  • Nokia SR OS
  • Any vendor with a text-based CLI
