About the Network Config Generator

This free network config generator is built for service provider and enterprise network engineers who need to provision or migrate large numbers of devices quickly. Instead of writing repetitive Cisco IOS XR, Juniper JunOS, or Nokia SR OS configurations by hand, you define a single CLI template once — then let the tool substitute your device-specific data automatically.

How it works

  1. Write a CLI template using {{VARIABLE}} placeholders (e.g. {{INTERFACE}}, {{IP}}, {{VRF}}). Download the sample Excel file to see the required format.
  2. Upload a CSV or Excel file with column names that match the template variables (e.g., {{VARIABLE}}). Each row generates one configuration.
  3. Generate 10,000+ configurations in milliseconds.
  4. Click Validate to confirm all variables are matched
  5. Click Generate All or select specific devices and generate
  6. Download as a .txt file or copy to clipboard

Supported platforms

  • Cisco IOS XR (NCS-5500, NCS-540, ASR9k)
  • Cisco IOS / IOS-XE
  • Juniper JunOS (MX, QFX, EX)
  • Nokia SR OS
  • Arista EOS
  • Any vendor with a text-based CLI
