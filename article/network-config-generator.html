Network Config Generator

By Dinuka Hasanka Wijesinghe · IP/MPLS Core Network Engineer

Provisioning a handful of devices by hand is fine. Provisioning fifty PE routers, or rolling out the same interface config across a hundred access switches, is a different problem — one typo in row 47 and you're chasing a ticket at 2 AM. In this article I want to share a tool I built to solve exactly that: a free, browser-based Network Config Generator that turns a spreadsheet of device data into ready-to-paste CLI configuration, in seconds, for any vendor.

Overview

Network Config Generator is a single-page web tool — no install, no backend, nothing leaves your browser. You upload a CSV or Excel file, write one working config as a template, mark the parts that change per device with {{VARIABLE}} placeholders, and the tool substitutes your spreadsheet data into that template row by row.

Because the template engine is plain text substitution rather than a vendor-specific parser, it works with any CLI syntax:

  • Cisco IOS-XE
  • Cisco IOS-XR (NCS-5500, NCS-540, ASR9k)
  • Cisco NX-OS (Nexus)
  • Juniper JunOS (MX, QFX, EX)
  • Arista EOS
  • Nokia SR OS
  • Anything else with a text-based CLI

Try it here: dinukahasanka.com/tools/config-generator.html

Requirements

None. It's a static web page — open it in any modern browser, on any OS. No Python, no pip installs, no scripts to run locally. All processing happens client-side, so device data never touches a server.

Usage

The workflow is five steps:

  1. Write the template. Paste one working config into the Template box and swap the parts that change per device for {{VARIABLE}} placeholders — e.g. {{INTERFACE}}, {{IP}}, {{VRF}}, {{HOSTNAME}}. Hit Save Template and it's there next time you open the tool.
  2. Load the data. Upload or drag in a CSV/Excel file whose column headers match your variable names — one row per device. No file handy? Paste Data takes cells copied straight out of Excel, and + Add Data lets you type a row in by hand.
  3. Check the data. The validation panel lists matched, missing, and unused variables before you generate anything. A duplicate checker flags identical rows and repeated values — a reused IP, VLAN, hostname, or interface — so you catch the copy-paste error before it becomes a config error.
  4. Generate. Generate All builds a config for every row (tested past 10,000 rows, sub-second), or tick specific devices under Select configs and run Generate Selected.
  5. Export. Copy straight to clipboard, or download as a single .txt, an Excel sheet with a Generated Config column, or a .zip with one file per device, named by whichever column you choose.

Spreadsheet structure

There's no fixed column schema — that's the difference from a lot of tools like this. Your column headers are your variable names. Write {{VLAN}} in the template and add a VLAN column to your sheet; write {{PEER_IP}} and add a PEER_IP column. The tool tells you if a template variable has no matching column, or if a column isn't being used anywhere.

Example

Say you're rolling out access-layer config across three switches, each with a couple of interfaces to configure. Instead of typing the same interface / description / switchport block six times by hand:

  1. Paste one interface config block into the template, replace the interface name, description, and VLAN with {{INTERFACE}}, {{DESC}}, {{VLAN}}.
  2. Fill six rows in the data editor (or a CSV) — one per interface, across your three switches.
  3. Hit Generate All.

Six correctly formed config blocks, ready to paste, with zero manual retyping.

As always — review generated configuration before pushing it to a production device. The tool doesn't know your network; it only knows your template and your data.

Summary

I built this because I was tired of hand-editing the same interface block forty times during a migration. If it saves you the same headache, that's the point of putting it up for free. It's part of a small suite of browser-based tools I maintain at dinukahasanka.com/#tools, alongside a Pre/Post Check diff tool and a Subnet/VLSM calculator.
